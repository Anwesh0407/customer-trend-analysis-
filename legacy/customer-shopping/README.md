# Legacy Project: Customer Shopping Behavior Analysis

This directory contains the original, preserved customer shopping behavior analytics project.
It is an earlier project analyzing a 3,900-record consumer shopping transaction dataset.

### Files Included:
- `Customer_Shopping_Behavior_Analysis.ipynb`: Exploratory data analysis, cleaning, median imputation, and feature engineering notebook.
- `customer_shopping_behavior.csv`: Original 3,900-row customer shopping dataset.
- `customer_behavior_sql_queries.sql`: 10 SQL business queries.
- `customer_behavior_dashboard.pbix`: Power BI interactive dashboard.

**Compliance & Isolation Notice:**
This dataset and analysis are completely separate from Amazon Vendor Assist (AVA). None of these files or records are mixed with Amazon product catalog data or used in AVA runtime models.
